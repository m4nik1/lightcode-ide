Loaded history is not restored into the Codex conversation

High

ThreadService creates a fresh SDK thread whenever its in-memory map is empty at apps/server/ThreadService.ts:34-48. After restarting the server, users can see persisted messages, but their next prompt has no prior AI context. Persist the Codex thread ID and pass it to resumeThread, or replay the stored history.

02

Reloading a thread can discard an in-progress response

Medium

setCurrentThread replaces the entire local message list with the database result at useAIChat.tsx:125-136. Switching away and back during generation removes the unfinished assistant placeholder. Later stream updates cannot find its local ID, leaving the response invisible until another reload.

03

Low

ChatBubbles.tsx:4 imports Shimmer, but the loading state still renders a plain <span>. This introduces a lint warning and leaves the new motion dependency and untracked shimmer component as dead code.
