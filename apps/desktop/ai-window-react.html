Electron + React

Render React inside a new AI window

The new Electron BrowserWindow needs to load your renderer. The simplest approach is to reuse the current React bundle and pass a query flag like ?window=ai so React can render a different screen.

The idea

A new BrowserWindow is already a separate Electron renderer process. You just need to load the same React app and tell it which UI to show.

1
React buttonCalls window.electronAPI.openAIWindow().
2
Preload IPCInvokes window.openAIWindow in the main process.
3
Main processCreates the AI BrowserWindow and loads React with ?window=ai.
4
React routingApp sees the query flag and renders AIWindow.
