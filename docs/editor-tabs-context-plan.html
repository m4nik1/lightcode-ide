Editor Tabs Context Integration Plan

EditorTabsContext should become the single source of truth for open tabs, the active file, tab selection, and tab closing. Then TopTabs renders from that shared state, and ModernEditor switches the modern-monaco model whenever activeFilePath changes.

Current Problems

  • EditorTabsProvider is not mounted in main.tsx.
  • EditorTabsContext.tsx uses currentTabs, but that variable is not defined.
  • getFileName() is used but not defined or imported in the context file.
  • openFile() is created inside the provider but is not exposed in the context value.
  • TopTabs.tsx keeps its own local tabs state instead of using context.
  • App.tsx passes setActiveFilePath, but that local state is commented out.
  • TopTabs.tsx references handleCloseTab and handleTabContextMenu, but they are not defined.
  • m4Editor.createEditor(filePath) creates a new Monaco model every time instead of reusing an existing model for an open file.

Target Ownership

The context should own:

  • tabs: the list of open editor tabs.
  • activeFilePath: the file currently shown in Monaco.
  • openFile(filePath): create a tab if needed and activate it.
  • selectTab(filePath): activate an existing tab.
  • closeTab(filePath): remove a tab and choose the next active file.

Mount The Provider

Wrap App in EditorTabsProvider from main.tsx.

Context Shape

The provider should expose the tab state and operations that other components need.

import { createContext, ReactNode, useContext, useState } from "react";
import type { EditorTab } from "../types/EditorTab";

type EditorTabsContextValue = {
  activeFilePath: string | null;
  tabs: EditorTab[];
  openFile: (filePath: string) => void;
  selectTab: (filePath: string) => void;
  closeTab: (filePath: string) => void;
  setTabs: React.Dispatch<React.SetStateAction<EditorTab[]>>;
};

const EditorTabsContext = createContext<EditorTabsContextValue | null>(null);

function getFileName(filePath: string) {
  return filePath.split(/[\\/]/).pop() ?? filePath;
}

export function EditorTabsProvider({ children }: { children: ReactNode }) {
  const [activeFilePath, setActivePath] = useState<string | null>(null);
  const [tabs, setTabs] = useState<EditorTab[]>([]);

  function openFile(filePath: string) {
    setTabs((currentTabs) => {
      const alreadyOpen = currentTabs.some((tab) => tab.filePath === filePath);

      if (alreadyOpen) {
        return currentTabs;
      }

      return [
        ...currentTabs,
        {
          id: filePath,
          name: getFileName(filePath),
          filePath,
          isModified: false,
        },
      ];
    });

    setActivePath(filePath);
  }

  function selectTab(filePath: string) {
    setActivePath(filePath);
  }

  function closeTab(filePath: string) {
    setTabs((currentTabs) => {
      const nextTabs = currentTabs.filter((tab) => tab.filePath !== filePath);

      if (activeFilePath === filePath) {
        const nextActiveTab = nextTabs[nextTabs.length - 1] ?? null;
        setActivePath(nextActiveTab?.filePath ?? null);
      }

      return nextTabs;
    });
  }

  return (
    <EditorTabsContext.Provider
      value={{
        activeFilePath,
        tabs,
        openFile,
        selectTab,
        closeTab,
        setTabs,
      }}
    >
      {children}
    </EditorTabsContext.Provider>
  );
}

export function useEditorTabs() {
  const context = useContext(EditorTabsContext);

  if (context == null) {
    throw new Error("useEditorTabs must be used inside EditorTabsProvider");
  }

  return context;
}

App Integration

App.tsx should read activeFilePath and openFile from context. Opening from the explorer should call openFile, not a local setActiveFilePath. 

const { activeFilePath, openFile } = useEditorTabs();

<FileExplorer folderPath={activeFolderPath} onFileOpen={openFile} />

<TopTabs editor={editor} />

<ModernEditor
  filePath={activeFilePath}
  folderPath={activeFolderPath}
  editor={editor}
/>

TopTabs Integration

TopTabs should not own tab data. It should render tabs from context and use context actions for selecting and closing tabs. 

import { useEditorTabs } from "../context/EditorTabsContext";

export default function TopTabs() {
  const { tabs, activeFilePath, selectTab, closeTab } = useEditorTabs();

  return (
    <div style={styles.strip}>
      {tabs.map((tab) => {
        const isActive = tab.filePath === activeFilePath;

        return (
          <div
            key={tab.id}
            role="tab"
            aria-selected={isActive}
            onClick={() => selectTab(tab.filePath)}
          >
            <span>{tab.name}</span>

            <button
              type="button"
              aria-label={`Close ${tab.name}`}
              onClick={(event) => {
                event.stopPropagation();
                closeTab(tab.filePath);
              }}
            >
              x
            </button>
          </div>
        );
      })}
    </div>
  );
}

ModernEditor Integration

ModernEditor can stay as the bridge between React state and modern-monaco. Whenever activeFilePath changes, it asks m4Editor to show that file. 

useEffect(() => {
  if (!filePath) {
    return;
  }

  void setupEditor(filePath);
}, [filePath]);

m4Editor Model Cache

m4Editor should keep one Monaco model per file path. That way, switching tabs switches models instead of recreating models and losing editor state. 

private models = new Map<string, mEditor.ITextModel>();

async createEditor(filePath: string) {
  this.monaco = this.monaco ?? await init();

  if (this.editor == null) {
    const container = this.editorRef.current;

    if (container == null) {
      console.warn("createEditor: editor container ref is not mounted");
      return;
    }

    this.editor = this.monaco.editor.create(container, {
      smoothScrolling: true,
      cursorSmoothCaretAnimation: "on",
      cursorBlinking: "smooth",
    });
  }

  const existingModel = this.models.get(filePath);

  if (existingModel != null) {
    this.currentModel = existingModel;
    this.editor.setModel(existingModel);
    return;
  }

  const nextModel = await new m4model().createModel(this.monaco, filePath);
  this.models.set(filePath, nextModel);
  this.currentModel = nextModel;
  this.editor.setModel(nextModel);
}

Data Flow

FileExplorer / TopBar
  -> openFile(filePath)
  -> EditorTabsProvider adds or selects tab
  -> activeFilePath changes
  -> TopTabs highlights the active tab
  -> ModernEditor receives filePath
  -> m4Editor switches the modern-monaco model

Implementation Order

  1. Mount EditorTabsProvider in main.tsx.
  2. Fix and type EditorTabsContext.tsx.
  3. Replace the old App.tsx file-opening flow with openFile.
  4. Refactor TopTabs.tsx to consume context instead of local tab state.
  5. Update m4Editor to cache Monaco models by file path.
