Run the server in an Electron utility process

Start the local tRPC server with the desktop app, wait until it is listening before opening a window, package the native Codex runtime, and shut the entire process tree down with Electron.

Electron utilityProcess tRPC 11 127.0.0.1:2024 Electron Forge + Vite

Target architecture

one app · three processes

Electron owns the server lifecycle. The renderer keeps using the existing http://localhost:2024 tRPC URL, while the server binds only to loopback.

Electron main Starts, monitors, and stops the server
→
Utility process Runs HTTP + tRPC on port 2024
→
Codex app-server Native child process over stdio
ℹ

Why utilityProcess? It gives Electron a Node-capable child process without requiring a system Node installation. It also exposes a parent message port for an explicit readiness handshake.

1

Make the HTTP server utility-aware

apps/server/index.ts

Bind to loopback, preserve the existing CORS rules, and notify Electron only after the listening event fires.

apps/server/index.ts 
import { createServer } from "node:http";
import { createHTTPHandler } from "@trpc/server/adapters/standalone";
import { appRouter } from "./appRouter.ts";

const PORT = 2024;
const HOST = "127.0.0.1";
const ALLOWED_ORIGINS = new Set([
  "null",
  "http://localhost:5173",
  "http://127.0.0.1:5173",
]);

const trpcHandler = createHTTPHandler({
  router: appRouter,
  createContext: () => ({}),
});

type UtilityParentPort = {
  postMessage(message: unknown): void;
};

const parentPort = (
  process as NodeJS.Process & { parentPort?: UtilityParentPort }
).parentPort;

const server = createServer((req, res) => {
  const origin = req.headers.origin;

  if (origin && ALLOWED_ORIGINS.has(origin)) {
    res.setHeader("Access-Control-Allow-Origin", origin);
    res.setHeader("Vary", "Origin");
    res.setHeader("Access-Control-Allow-Methods", "GET,POST,OPTIONS");
    res.setHeader("Access-Control-Allow-Headers", "content-type,trpc-accept");
  }

  if (req.method === "OPTIONS") {
    res.statusCode = 204;
    res.end();
    return;
  }

  trpcHandler(req, res);
});

server.once("error", (error) => {
  parentPort?.postMessage({
    type: "startup-error",
    message: error.message,
  });
  process.exitCode = 1;
});

server.listen(PORT, HOST, () => {
  const url = `http://${HOST}:${PORT}`;
  console.log(`Server listening at ${url}`);
  parentPort?.postMessage({ type: "ready", url });
});

function shutdown() {
  server.close(() => process.exit(0));
}

process.once("SIGINT", shutdown);
process.once("SIGTERM", shutdown);

Own the process from Electron main

src/main/serverProcess.ts

Resolve the correct platform package, fork the bundled server, forward its logs, and wait for ready. A timeout or early exit prevents a broken renderer from opening.

apps/desktop/src/main/serverProcess.ts 
import { app, utilityProcess, type UtilityProcess } from "electron";
import { createRequire } from "node:module";
import path from "node:path";

let child: UtilityProcess | undefined;
let startPromise: Promise<void> | undefined;

const targets = {
  "linux-x64": ["@openai/codex-linux-x64", "x86_64-unknown-linux-musl"],
  "linux-arm64": ["@openai/codex-linux-arm64", "aarch64-unknown-linux-musl"],
  "darwin-x64": ["@openai/codex-darwin-x64", "x86_64-apple-darwin"],
  "darwin-arm64": ["@openai/codex-darwin-arm64", "aarch64-apple-darwin"],
  "win32-x64": ["@openai/codex-win32-x64", "x86_64-pc-windows-msvc"],
  "win32-arm64": ["@openai/codex-win32-arm64", "aarch64-pc-windows-msvc"],
} as const;

function getTarget() {
  const key = `${process.platform}-${process.arch}` as keyof typeof targets;
  const target = targets[key];
  if (!target) throw new Error(`Unsupported platform: ${key}`);
  return target;
}

function resolveCodexPath() {
  const [packageName, triple] = getTarget();
  const executable = process.platform === "win32" ? "codex.exe" : "codex";

  if (app.isPackaged) {
    return path.join(process.resourcesPath, triple, "bin", executable);
  }

  const runtimeRequire = createRequire(
    path.join(app.getAppPath(), "package.json"),
  );
  const packageJson = runtimeRequire.resolve(`${packageName}/package.json`);

  return path.join(
    path.dirname(packageJson),
    "vendor",
    triple,
    "bin",
    executable,
  );
}

export function startServerProcess() {
  if (startPromise) return startPromise;

  startPromise = new Promise<void>((resolve, reject) => {
    const server = utilityProcess.fork(
      path.join(__dirname, "electronServer.js"),
      [],
      {
        serviceName: "Lightcode Server",
        stdio: "pipe",
        env: {
          ...process.env,
          LIGHTCODE_CODEX_PATH: resolveCodexPath(),
        },
      },
    );

    child = server;
    server.stdout?.on("data", (data) =>
      console.log(`[server] ${data.toString().trimEnd()}`),
    );
    server.stderr?.on("data", (data) =>
      console.error(`[server] ${data.toString().trimEnd()}`),
    );

    const timeout = setTimeout(() => {
      server.kill();
      reject(new Error("Server startup timed out"));
    }, 15_000);

    server.on("message", (message: unknown) => {
      if (!message || typeof message !== "object" || !("type" in message)) return;

      if (message.type === "ready") {
        clearTimeout(timeout);
        resolve();
      } else if (message.type === "startup-error") {
        clearTimeout(timeout);
        reject(new Error(String(message.message)));
      }
    });

    server.on("exit", (code) => {
      child = undefined;
      startPromise = undefined;
      if (code !== 0) {
        console.error(`Lightcode server exited with code ${code}`);
      }
    });
  });

  return startPromise;
}

export function stopServerProcess() {
  child?.kill();
  child = undefined;
  startPromise = undefined;
}
4

Wait before opening windows

src/main/main.ts

Start after Electron is ready, then create the requested window. A startup failure shows one actionable dialog and exits.

apps/desktop/src/main/main.ts 
import {
  startServerProcess,
  stopServerProcess,
} from "./serverProcess";

app.on("ready", async () => {
  try {
    await startServerProcess();

    if (isMac) {
      app.dock?.setIcon(iconPath);
      createMacApplicationMenu();
    }

    if (shouldOpenAIWindowOnly) {
      createAIWindow();
    } else {
      createWindow();
    }
  } catch (error) {
    dialog.showErrorBox(
      "Unable to start Lightcode",
      error instanceof Error ? error.message : String(error),
    );
    app.quit();
  }
});

app.on("before-quit", () => {
  stopServerProcess();
});

Verification

definition of done
  1. Run npm run desktop without starting npm run server separately.
  2. Confirm the renderer opens only after the server logs Server listening at http://127.0.0.1:2024.
  3. Call a tRPC route and send an AI request to prove both child-process layers work.
  4. Quit Electron and confirm port 2024 and the Codex process are both gone.
  5. Occupy port 2024, launch Electron, and confirm it shows a startup error without opening a renderer.
  6. Package the desktop app and confirm the target-triple Codex directory exists under the application resources.
  7. Launch the packaged app without a system Node installation and repeat the tRPC and AI smoke tests.
